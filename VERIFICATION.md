# Перевірка ЛР №4 (варіант 7)

Перевірка складу архіву та статичного коду:

- В архіві є `index.html`, `style.css`, `script.js`, `posts.json`, `fallback-posts.js`, `placeholder.svg`, звіт і промпти.
- `posts.json` — валідний JSON: 27 статей із потрібними полями, 27 унікальних ID.
- `script.js` і `fallback-posts.js` проходять `node --check`.
- У HTML немає повторних ID; JavaScript-посилання на ID мають відповідні елементи в документі.
- Реалізовано `fetch('./posts.json')` із перевіркою `response.ok`, завантаження у нижній частині HTML, делегування натискань для карток, комбіновану фільтрацію, пошук, пагінацію по 9, `IntersectionObserver`, localStorage і валідацію email.
- Резервні дані з `fallback-posts.js` використовуються тільки при відкритті через `file://`; перевіряти саме Fetch API треба на Live Server / GitHub Pages.

Не підтверджено лише статичною перевіркою:

- Фактичне оновлення GitHub-репозиторію та успішний деплой Pages.
- Повноцінне тестування інтерактивності у браузері на реальному вебхостингу, зокрема роботи Bootstrap Modal, зовнішніх фотографій та CDN-ресурсів.
- Використання Google Gemini: у наявних матеріалах промпти від ChatGPT.
